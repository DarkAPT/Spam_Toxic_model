# Система автоматической модерации контента

Система автоматической модерации текстового контента с использованием двух моделей машинного обучения для выявления токсичных сообщений и спама. Проект демонстрирует полный цикл разработки ML-системы: от подготовки данных до развертывания REST API.

## Функциональность

- **Двойная классификация контента**: одновременное обнаружение токсичности и спама
- **Трехуровневая система решений**: блокировка (block), проверка модератором (review), разрешение (allow)
- **Логирование предсказаний**: сохранение всех запросов в базу данных SQLite
- **REST API**: удобный интерфейс для интеграции с внешними системами
- **Фильтрация истории**: получение логов с фильтрацией по решению и пагинацией


## Технологический стек

### Backend
- **FastAPI** - современный веб-фреймворк для создания API
- **SQLite** - легковесная база данных для хранения логов
- **SQLAlchemy** - ORM для работы с базой данных
- **Pydantic** - валидация данных и управление настройками

### Машинное обучение
- **PyTorch** - фреймворк для глубокого обучения
- **Transformers** (BERT) - предобученная модель для анализа токсичности
- **Scikit-learn** - классические алгоритмы ML и метрики
- **NLTK** - обработка естественного языка
- **pymorphy3** - морфологический анализ русского языка


## Установка и запуск

### Пошаговая установка

```bash
# 1. Клонирование репозитория
git clone https://github.com/your-username/moderation-system.git
cd moderation-system

# 2. Создание виртуального окружения
python -m venv venv
source venv/bin/activate  # для Linux/Mac
# venv\Scripts\activate  # для Windows

# 3. Установка зависимостей
# Для установки зависимостей необходимых только для работы API
pip install -r requirements_api.txt
# Для установки всех зависимостей, включая API и бибилотеки при проведении сравнительно анализа моделей(notebooks)
# pip install -r requirements_full.txt

# 4. Запуск приложения
python3 main.py
```

Приложение будет доступно по адресу: http://localhost:8000

## API Endpoints

### POST /predict

Основной эндпоинт для классификации текста

Запрос:
```json
{
  "text": "Ваш текст для анализа"
}
```
Ответ:

```json
{
  "decision": "allow|review|block",
  "spam_confidence": 0.123,
  "toxic_confidence": 0.456
}
```

### GET /get_prediction_logs

Получение истории предсказаний с фильтрацией

Параметры:

decision (опционально): фильтр по решению (block/review/allow)

limit (по умолчанию 10): количество записей


### GET /health
Проверка состояния системы и загруженных моделей

## Модели машинного обучения
### 1. Модель токсичности
Архитектура: rubert-tiny2 (fine-tuned)

Точность на тесте: 96.2%

Пороги срабатывания: block > 0.95, review > 0.4

### 2. Модель спама
Архитектура: Кастомная полносвязная нейронная сеть


Точность на тесте: 98%

Пороги срабатывания: block > 0.5, review > 0.3

## Используемые датасеты
Для обучения моделей использовались два открытых датасета русскоязычных текстов, размеченных по заданным категориям.

### Датасет для классификации спама
Для обучения модели обнаружения спама использовался датасет Russian Spam Detection, доступный на платформе Hugging Face

Источник: ruSpamModels/russian-spam-detection
Ссылка на датасет: https://huggingface.co/datasets/ruSpamModels/russian-spam-detection

Содержание: Набор текстовых сообщений, размеченных на два класса: спам и не-спам (ham)

Лицензия: CC BY-NC 4.0 (Creative Commons Attribution-NonCommercial)

### Датасет для классификации токсичности
Для определения токсичности комментариев был выбран датасет Toxic Russian Comments, размещенный на платформе Kaggle.

Источник: Toxic Russian Comments Dataset
Ссылка на датасет: https://www.kaggle.com/datasets/alexandersemiletov/toxic-russian-comments

Описание: Содержит комментарии из социальной сети ok.ru. Каждый комментарий размечен одной или несколькими метками, соответствующими уровню токсичности

Лицензия: CC BY-NC-SA 4.0 (Creative Commons Attribution-NonCommercial-ShareAlike)
